## 这次运行是什么

| | |
|---|---|
| 设备 | 鸿蒙车机 |
| 设备报告的 Android 版本 | Android 12 |
| 指令语言 | 中文，即上面那句 |
| 背后驱动智能体的模型 | `qwen3.8-flash` |
| 结果 | 1 个任务，退出 0，应用记录的运行时长 120s |
| 素材 | 2 分 20 秒，4K（3840x2160）HEVC，对着屏幕翻拍 |

`120s` 是应用历史里为这次运行打的数字（1/1 个任务），是整条指令的墙上时间，
不是各次点击耗时之和。

## 画面里依次发生了什么

| 视频时间 | 屏幕上 |
|---|---|
| 0:00 | 把指令输入应用的「指令」输入框，点「运行」 |
| 0:02 – 0:03 | 运行开始；进度悬浮层把指令和「停止」按钮钉在所有界面之上 |
| 0:05 – 0:20 | 智能体自己离开本应用：打开应用中心，找到 QQ音乐，点进去 |
| 0:20 – 0:50 | 在 QQ音乐里：打开搜索，唤起键盘 |
| 0:50 – 1:10 | 输入 `Coldplay`，提交，等结果 |
| 1:10 – 1:55 | 选中搜索结果的第一个，开始播放 |
| 1:55 – 2:20 | 回到本应用：「历史」里这次运行已完成，打开它的报告 |

点下「运行」之后屏幕再没被碰过。悬浮层全程都在 —— 那个「停止」按钮就是随时
退出的口子。

### 仓库里这份是怎么来的

```bash
ffmpeg -i midscene-android-demo-4k.mp4 \
  -vf scale=1920:-2 \
  -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p \
  -c:a aac -b:a 96k -ac 2 \
  -movflags +faststart \
  demo-1080p.mp4
```

`+faststart` 在这里是有用的：它把 moov atom 挪到文件开头，所以视频不必等 23 MB
全部到位就开始播。源是 4K 30fps、34 Mbit/s；这份是 30fps、约 1.3 Mbit/s。

源文件的音轨是一条实际上无声的 AAC 流（2 kbit/s），所以转码后保留一条静音 AAC
轨，而不是假装里面有解说。

## 这个演示覆盖到哪

它展示的是「运行」这条路径：一条自然语言指令、一台车机、一份跑完的报告。没有

README](../../README.zh.md) 里。
